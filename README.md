# A & L Planning

A & L Planning is a planning app designed primarily for couples.

The goal is to combine tasks, shared lists, grocery shopping, calendars, and future habit tracking into one clean and intuitive experience.

## Tech Stack

- React
- Vite
- Supabase
- GitHub Pages
