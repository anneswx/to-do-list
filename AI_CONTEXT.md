# Project Vision

A & L Planning is a planning app for couples.

The app should feel simple enough to replace sticky notes and Apple Reminders, while being powerful enough to manage daily life together.

The experience should prioritize:

- simplicity
- speed
- consistency
- shared planning
- minimal visual clutter

# Development Rules

- Mobile-first design.
- Reuse components whenever possible.
- Avoid duplicate CSS.
- Colors should come from shared design tokens.
- Pages should focus on layout.
- Business logic should stay outside page components whenever possible.
- Keep components small and reusable.

---

# UI Principles

- Apple-inspired
- Rounded corners
- Minimal borders
- Plenty of whitespace
- Consistent spacing
- Soft colors
- One primary action per screen
